# Quickstart: Enhanced AI 다운로드 및 고지 UX 검증

## 전제

- Chrome 확장 프로그램이 로드되어 있고(content script가 `https://github.com/*`에서 동작),
- Enhanced 컨텍스트 메뉴 아이템이 존재해야 한다.
  - 현재 코드: `extension/src/background/context-menus.ts`의 `"ot-enhanced-translate"`

## 수동 QA 시나리오

### 1) 모델이 미다운로드 상태일 때: Wi‑Fi 권장 고지/동의가 먼저 표시되는지

1. (가능하면) Chrome 프로필을 “비어있는 새 사용자 데이터 디렉터리”로 실행해 모델이 없는 상태를 만든다.
   - 문서 참고: `--user-data-dir`로 모델 UX 테스트
2. GitHub 페이지에서 텍스트를 선택하고, 우클릭 컨텍스트 메뉴의 **고정밀 번역 (Enhanced)** 를 선택한다.
3. 기대 결과:
   - 다운로드가 필요한 경우, Enhanced 요청 직후 **Wi‑Fi 권장 고지/명시적 동의 UI**가 먼저 표시된다.
   - 동의 버튼을 누르기 전에는 Translator 다운로드/진행이 시작되지 않아야 한다(창/오버레이는 동작하지만 진행률이 “시작되지 않은” 상태여야 함).

### 2) 동의 후: 다운로드 진행률이 여러 번 갱신되는지

1. 시나리오 1에서 Wi‑Fi 고지 UI에서 **동의하고 다운로드**를 클릭한다.
2. 기대 결과:
   - 다운로드 진행률 UI가 최소 2회 이상 갱신된다.
   - 다운로드 완료 이후에는 “추출/메모리 로딩” 같은 단계가 사용자에게 명확히 전달되거나(또는 인디테르미네이트 상태로 전환), 완료 상태가 명확히 표시된다.
3. 완료 후:
   - **고정밀 번역 결과** 오버레이가 표시된다.

### 3) 다운로드 중 취소: enhanced가 자동 전환되지 않고 “취소됨” + 명시적 다음 행동을 제공하는지

1. 시나리오 2에서 다운로드가 진행 중일 때 **취소** 버튼을 클릭한다.
2. 기대 결과:
   - 다운로드/설치가 중단되고,
   - enhanced 요청은 취소 처리되며,
   - 자동으로 기본 번역이 실행되지 않는다.
   - “취소됨” 상태 메시지가 표시되고,
   - **“기본 번역으로 계속”** 같은 버튼이 제공된다.

### 4) 다운로드 실패/차단: 오류 메시지 + “기본 번역으로 계속” 버튼 제공, 자동 전환 금지

1. 오프라인/제한된 네트워크 등으로 다운로드가 실패하도록 유도하거나,
2. Chrome/디바이스에서 Translator 사용이 차단되도록 설정한다(환경에 따라).
3. 기대 결과:
   - 실패 원인을 사용자에게 이해 가능한 오류 메시지로 표시한다.
   - 자동으로 기본 번역으로 전환하지 않는다.
   - **“기본 번역으로 계속”** 버튼을 제공하며, 버튼 클릭 시 동일 입력/대상에 대해 selection 기반 기본 번역을 즉시 재시도한다.

## 최소 검증 체크리스트(정량/정성)

- SC-001: 고지 표시까지 평균 1초 이내(수동 측정/추적)
- SC-002: 진행 상태 최소 2회 갱신 + 완료 시점 상태 명확
- SC-003: 사용자 테스트에서 고지/취소 이해도 90% 이상(가능하면 인터뷰/설문)
- SC-004: 실패 시 2초 이내에 오류 메시지 + 다음 행동 안내
